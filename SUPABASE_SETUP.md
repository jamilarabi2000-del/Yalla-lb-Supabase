# Supabase Setup

This repository uses Supabase for authentication, PostgreSQL data, storage, and CMS content. Configure `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` (or `VITE_SUPABASE_ANON_KEY`) in the deployment environment.

The production `Yalla-lb` repository remains separate from this Supabase migration repository.
